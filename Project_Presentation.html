🎯 Skill-Gap HR Intelligence Portal

A Text Mining & NLP-Based Web Application for Skill Gap Analysis

📌 Project Overview

The Skill-Gap HR Intelligence Portal is a full-stack web application that uses Natural Language Processing (NLP) and Text Mining to analyze job descriptions, extract relevant skills, and provide a personalized competitiveness score to users. It bridges the gap between a candidate's existing skills and current market requirements.

Problem Statement: Job seekers often don't know which specific skills they are missing compared to what the market demands. This portal automates that analysis using text mining techniques — helping users identify gaps, get a match score, and find certifications to upskill.

🔬 Text Mining & NLP — How It Works

This is the core intelligence of the portal. The NLP pipeline processes raw text through multiple stages to extract meaningful skill information.

Step 1: Text Preprocessing

Raw Text→ Lowercase→ Remove Special Chars→ Tokenization→ Stopword Removal
StageWhat HappensExample
LowercasingConverts all text to lowercase for uniform matching"Python Developer" → "python developer"
Special Char RemovalStrips numbers, punctuation, symbols using regex re.sub(r'[^a-zA-Z\s]', '', text)"3+ years of exp." → "years of exp"
TokenizationSplits text into individual words (tokens) using NLTK's word_tokenize()"python and flask" → ["python", "and", "flask"]
Stopword RemovalRemoves common English words (a, the, is, and, etc.) using NLTK's stopwords corpus["python", "and", "flask"] → ["python", "flask"]

Step 2: Skill Extraction (Pattern Matching)

After preprocessing, each cleaned token is compared against the predefined skill database (66 skills categorized as Hard or Soft):

for each token in processed_tokens: if token exists in hard_skills_list → Add to user's Hard Skills elif token exists in soft_skills_list → Add to user's Soft Skills

This extraction runs twice:

  1. On the user's pasted resume/JD → extracts user's current skills
  2. On the market job description from the database → extracts market-required skills

Step 3: Competitiveness Score Calculation

Formula:
Competitiveness Score = (Matched Skills / Total Market Skills) × 100
VariableMeaning
matched_skillsSkills found in BOTH user text AND market JD
total_market_skillsTotal skills required by the market job description
scorePercentage match (0–100%), rounded to 2 decimal places

Step 4: Gap Analysis

missing_skills = [skill for skill in market_skills if skill NOT in user_skills]

Skills present in the market JD but absent from the user's text are flagged as critical skill gaps and displayed as red badges on the results page.

A mapping of missing skills → industry-recognized certifications provides actionable upskilling advice:

✨ Key Features

1. 🔐 Secure Authentication

  • Password hashing with Bcrypt — passwords never stored in plain text
  • Session management with Flask-Login — persistent login state
  • Protected routes — only authenticated users can access dashboard, search, and compare

2. 🔍 Job Search Engine

  • Searches across 52 detailed job roles from 13+ industry domains
  • Uses SQL LIKE query via SQLAlchemy's .contains() for flexible partial matching
  • Domains covered: AI/ML, Web Dev, DevOps, Cybersecurity, Marketing, Finance, HR, Product, Design, Data Science, Blockchain, Gaming, Robotics

3. 🧠 NLP-Powered Skill Extraction

  • NLTK library for tokenization (word_tokenize) and stopword removal
  • Regex-based text cleaning to remove noise from input
  • Matches tokens against 66 predefined skills (54 Hard + 12 Soft)
  • Dual extraction — processes both user text AND market job description

4. 📊 Visual Analytics Dashboard

  • Doughnut Chart (Chart.js) — visual ratio of matched skills vs gaps
  • Animated Progress Bar — competitiveness percentage with dynamic color
  • Color-coded Badges — green for matched skills, red for skill gaps

5. 🎨 Dynamic Theming

The results page dynamically changes its accent color based on the job category:

6. 📜 Certification Recommendations

  • Fallback suggestions when no specific skill-to-cert match is found

7. 💰 Salary Insights
